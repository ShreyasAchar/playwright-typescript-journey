# 🎭 Playwright + TypeScript: Zero to Pro

> A public, day-by-day learning journal. I'm learning Playwright and TypeScript **from absolute zero**, and I write down every concept, every line of code and every mistake, so that juniors can follow the same path.

If you're a beginner, you're in the right place. You don't need any prior programming knowledge. Start at **Day 1** and go in order.

---

## 📌 How to use this repo

1. Every day of learning has its **own folder**, for example `phase-1-typescript-foundations/day-01-setup-and-first-program/`.
2. Inside each day's folder:
   - `README.md` holds **the notes**: concepts explained simply, examples, common mistakes and a quiz.
   - `.ts` files hold **the code** I wrote that day, with comments.
   - `exercises/` holds practice problems and my solutions.
3. Read the notes first, then type the code yourself. **Don't copy and paste.** Typing it is how you learn.
4. Check the **Progress Tracker** below to see where the journey is.

### Setup for following along
```bash
# 1. Install Node.js (LTS) from https://nodejs.org
# 2. Clone this repo
git clone https://github.com/ShreyasAchar/playwright-typescript-journey.git
cd playwright-typescript-journey
# 3. Install dependencies (once package.json exists, from Day 1 onwards)
npm install
```
